# ClinicalMirror

ClinicalMirror is a hackathon prototype for practising clinical communication with fictional AI patients. Learners complete a short scenario and receive formative feedback on empathy, clarity, and de-escalation, including transcript evidence and a retry plan.

## What you need

- Node.js 20.9 or newer
- A Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey)
- Chrome or Edge if you want browser speech recognition; typed chat works without microphone support

No external speech, avatar, database, or authentication account is required for local testing. Voice input and spoken replies use browser capabilities. Conversation text is sent to Gemini, so use fictional data only.

## Run locally

1. Install dependencies:

   ```powershell
   npm install
   ```

2. Copy `.env.example` to `.env.local` and replace the placeholder:

   ```powershell
   Copy-Item .env.example .env.local
   ```

3. Start the app:

   ```powershell
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000).

For a quick demo, choose **Angry Family Member**, accept the privacy notice, and try two or more learner responses before ending the session. The Mental Health Crisis scenario is intentionally held for faculty review until safeguarding and escalation behaviour is formally validated.

## Prototype boundaries

- Educational and formative only; it does not establish clinical competence or provide clinical advice.
- The patient emotion and intensity values are generated by the same AI model, so they are supporting interface signals rather than independent evidence.
- API prompts stay server-side and inputs are length-checked, but this prototype does not yet include accounts, persistent storage, institutional consent, audit logs, or production monitoring.
- Before any real learner study, obtain faculty, privacy, and ethics approval and define data retention and incident-response procedures.
